# 避免制式設計

本檔用於建立新視覺方向或審查確實存在的視覺問題，不是常見元件黑名單。既有產品的卡片、藍色按鈕、等寬 grid 或系統字體本身不是 finding；判斷它們是否服務內容與操作，不能為了不普通而重做。

## 有證據的退化訊號

- **沒有主次：** 所有卡片、標題、CTA 同時搶焦點。先調資訊層級，不直接換成另一種流行版型。
- **surface 不一致：** 每區各用不同陰影、玻璃感、圓角或 accent。沿用同一套 tokens 與產品層級，避免拼貼多份模板。
- **以色線裝飾容器：** 一般容器的 accent rail／頂線／左線及等價替代，依 [主契約](../SKILL.md) 禁止；保留有功能意義的語意色與例外，不把所有顏色刪掉。
- **只畫預設狀態：** loading、empty、error、focus、長文字或首次建立入口不可用。從真正使用流程判斷，不靠卡片美化掩蓋。
- **展示干擾操作：** hover／reveal 遮住資訊、造成 layout shift 或拖慢捲動。移除無價值動效，保留必要 feedback 與 reduced-motion 支援。
- **文案對錯對象：** 在產品畫面介紹自己的設計方法，或虛構商業數字增加說服力。改為使用者需要的內容，不補造事實。
- **素材冒充：** 用 placeholder、emoji 或臨時造型替代必要品牌素材卻不揭露。取得合法來源或明確說明替換。

## 改善方式

由可觀察問題選最小有效調整：內容順序、文字層級、spacing、對比、狀態、操作可達性。只有這些方式不足且本次授權涵蓋重設計時，才改整體視覺方向。

不強制固定 CTA 數量、字體數、欄數、padding、section 高度或動畫時間，也不把「看起來能放到其他產品」直接判成失敗。成熟內部工具可以一致、熟悉；使用者特別要求品牌表現時，再建立有根據的差異。
