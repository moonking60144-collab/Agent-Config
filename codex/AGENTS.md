# AGENTS.md

## 必定注意事項

- 使用者目前常在 Windows 本機與 WSL 混合環境下工作，不能預設所有檔案都在同一側。
- 只要使用者提供的是 Windows 絕對路徑，例如 `C:\Users\moonk\...`，就必須先以 **Windows 檔案** 為目標理解，不能擅自改寫成 Linux 專案路徑心智模型。
- 只要使用者提供的是 WSL / Linux 路徑，例如 `/home/...`、`/mnt/c/...`，就必須先以 **WSL 檔案** 為目標理解，不能回退成 `C:\...` 的預設假設。
- 如果 agent 目前運行在 WSL，但要操作的是 Windows 路徑，必須先明確完成路徑換算，再進行讀寫、搜尋、執行命令。
- 如果 agent 目前運行在 Windows，但要操作的是 WSL 路徑，也必須先確認對應位置與可達性，再進行操作。
- 在開始任何檔案修改、搜尋、執行腳本、安裝依賴之前，先確認這次任務的實際目標路徑屬於 Windows 還是 WSL。
- 不得因為 shell 是 PowerShell、bash、WSL 或 Windows Terminal，就反向推定目標檔案一定在同一個檔案系統。
- 當路徑歸屬不清楚時，先確認再動手；不要靠猜測直接改檔。
- 回覆使用者時，若本次任務涉及跨 Windows / WSL 路徑操作，應簡短說明目前實際使用的是哪一側路徑。
